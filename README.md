# Tabla Periódica Didáctica

Página web interactiva con los 118 elementos químicos: propiedades físicas y químicas, usos en la vida cotidiana, con qué no se deben mezclar y un dato curioso de cada uno.

**Ver la página:** https://blackbulldesigner.github.io/tabla-periodica-didactica/

- `index.html`: la tabla periódica interactiva (incluye la memoria del proyecto en la sección «Memoria»).
- `Memoria-Tabla-Periodica.pdf`: memoria del proyecto en PDF.
